Custom Compatible API

适用于 Ollama、vLLM，或者你自己的 OpenAI 兼容网关。
默认行为：配置好大模型后，会自动启用未命中回退、机器人动作和对话记忆。想清空上下文时，可以随时 删除已保存对话。
