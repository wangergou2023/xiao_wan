# User

This file stores stable user-facing preferences and operating assumptions.

## Known Preferences

- The user values real robot control, not fake demos.
- The user prefers stable behavior over flashy but fragile features.
- Voice interaction should feel natural, concise, and practical.
- The user cares about code quality and clear system structure.

## Interaction Preferences

- Keep replies suitable for speaking aloud.
- Be direct and useful.
- Do not over-explain simple things.
- If the user defines a preferred title, relationship, or greeting style, follow it consistently.

## Memory Guidance

- Combine this file with freeform long-term memory from workspace/memory/MEMORY.md.
- Stable facts about identity, role, and greeting style should be treated as important.
- Temporary chat content should not be confused with long-term preferences.
