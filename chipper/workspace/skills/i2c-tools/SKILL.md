# I2C Tools

使用 i2c-tools 工具集检测和管理 Linux I2C 总线及连接的设备。

## 何时使用

当用户需要：
- 扫描 I2C 总线上的设备
- 检测可用的 I2C 总线
- 读取/写入 I2C 设备寄存器
- 调试 I2C 连接问题

## 使用步骤
先确认用户明确要进行 I2C 检测或写寄存器，再通过 `system_cmd` 执行命令。

### 1. 检测可用的 I2C 总线
```bash
i2cdetect -l
```

### 2. 扫描指定总线上的设备
```bash
i2cdetect -y <总线号>
```
例如：`i2cdetect -y 1`

### 3. 读取设备寄存器
```bash
i2cget -y <总线号> <设备地址> <寄存器地址>
```
例如：`i2cget -y 1 0x50 0x00`

### 4. 写入设备寄存器
```bash
i2cset -y <总线号> <设备地址> <寄存器地址> <值>
```
例如：`i2cset -y 1 0x50 0x00 0xFF`

### 5. 批量读取寄存器（i2cdump）
```bash
i2cdump -y <总线号> <设备地址>
```
例如：`i2cdump -y 1 0x50`

## 示例

**扫描 I2C-1 总线上的所有设备：**

（显示在 0x50 地址检测到设备）

## 注意事项

- 需要 root 权限运行 i2c-tools 命令
- 设备地址为 7 位地址（不含读写位）
- `--` 表示该地址无设备响应
- `UU` 表示该地址被内核驱动占用
- 使用 `-y` 标志跳过确认提示
- 写寄存器前要非常谨慎，除非用户明确要求，否则优先只读不写

## 工具列表

| 工具 | 用途 |
|------|------|
| `i2cdetect` | 检测 I2C 总线和设备 |
| `i2cdump` | 读取设备所有寄存器 |
| `i2cget` | 读取单个寄存器 |
| `i2cset` | 写入寄存器 |
| `i2ctransfer` | 高级传输（组合读写）|
